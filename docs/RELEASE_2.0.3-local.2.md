# 2.0.3-local.2 本地修复测试版

2026-11-09，基于上一版 2.0.3-local.1，非上游官方 Release。

## 本次修复

上一版修复了网页登录对象解析，但没有覆盖真实 WebView2 的会话 Cookie 导出格式。
在真实 WebView2 本地测试中，HttpOnly 会话 Cookie 的 expires 被导出为
`Mon, 01 Jan 0001 00:00:00 GMT`。这是 .NET DateTime.MinValue，表示没有持久过期时间。
Python 的邮件日期解析器将其中的 0001 年解释成 2001 年，原程序随即把登录 Cookie 当作已过期而丢弃。

本版识别该会话标记，保留其 expires=None，确保 Cookie 能从 WebView2 经过加密结果文件传入 requests。
真正过期的 Cookie 仍按过期处理，不会统一延长或取消 Cookie 的过期限制。

## 登录状态保存

登录窗口使用私密 WebView2 窗口，因此单独打开一个新登录窗口时不会继承之前的浏览器状态。
应用的自动恢复依赖身份验证成功后保存的 Windows DPAPI 加密账户文件，启动时会重新验证。
之前验证一直失败，也就没有保存成功的账户；本次修复针对的正是验证前丢失会话的问题。

- `tests/login_regression.py`：13 项通过，其中新增会话标记、真实过期、正常持久 Cookie、加密保存后读取等 4 项。
- `tests/webview_cookie_transfer.py`：真实 WebView2 -> 关闭窗口 -> DPAPI 加密结果 -> requests -> 本地身份端点的完整测试通过。修复前同一测试返回未认证，修复后返回已认证。该测试只使用本地虚构 Cookie。
- 原有 33 项下载/API/存储测试、6 项任务移除测试通过；UI 与 9 种布局组合通过。
- 打包后的 2.0.3-local.2 exe 启动、FFmpeg、WebView2 与加密登录结果传递自检通过。
- 检测到现有正式安装后，安装验证改用独立 AppId 的临时安装包；安装、安装后启动、与交付程序的哈希比对、卸载和测试用户数据保留全部通过。正式安装的版本与路径保持不变。
- 用户手动登录后的真实中国大学 MOOC 源码验证通过：登录窗口关闭后身份验证成功；Windows DPAPI 加密保存并重新读取后，真实网站再次验证成功。此项验证未代替安装版重启测试。

## 安装测试

关闭旧程序，安装 `MOOCDownloader-Setup-2.0.3-local.2-x64.exe`，确认左下角版本为 2.0.3-local.2。
在“设置”登录一次；成功显示“已验证登录”后，退出并重新启动应用，观察是否自动恢复已验证账户。

本版仍不支持此前发现的加密视频格式；登录修复与加密视频下载是两个独立问题。
