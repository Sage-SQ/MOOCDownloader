# 2.0.3-local.3 本地修复测试版

本版新增中国大学 MOOC 网页播放器使用的加密 HLS 下载支持，保留 local.2 的登录修复。

## 原因和处理

课程是否收费与媒体是否加密无关。目标免费课程《环境与资源保护法》返回的三档视频均带有
`e=true`、`secondaryEncrypt=true` 和播放授权封装。旧版只支持未加密视频，因此主动停止下载。
即使成功登录，服务端仍返回相同的加密格式；原始播放列表地址缺少播放器补充的授权时会返回 HTTP 400。

本版适配网页播放器的授权封装、HLS 地址格式、二次加密播放列表及密钥；随后按标准 AES-128
和播放列表指定的 IV 或媒体序列号解密分片，再用 FFmpeg 封装 MP4。授权和密钥不写入日志或任务队列。
暂停后保留分片缓存，恢复时重新取得播放授权。此功能仍以源站返回成功的资源授权为前提。

支持上述网页加密协议及普通 AES-128 HLS；不宣称支持全部 DRM、SAMPLE-AES、加密初始化片段、直播、
独立音轨或字节范围播放列表。协议适配依据 2026-11-09 源站播放器，平台更新可能需要再次适配。

## 验证

- 新增 11 项加密播放测试，覆盖官网 JavaScript 生成的虚构授权样本、播放列表和密钥解码、
  序列 IV、显式 IV、损坏及未知版本、画质档位、不完整播放列表、任务解析、暂停续传及真实 FFmpeg 合成/解码。
- 原有 13 项登录回归、33 项 API/下载/存储及 6 项任务移除测试通过。
- 在已登录账户下完整下载目标课程第 1 个视频，源站时长 562 秒，MP4 大小 60,190,271 字节；
  全片 FFmpeg 解码通过，解码错误输出为零。第 1、55、109 个视频的播放列表均能解码，
  分别包含 57、41、63 个分片，均为 AES-128。未测试全部 109 个视频。
- 最终 exe 的启动、真实 AES-128 解密、FFmpeg、WebView2 和登录通信自检通过；
  独立 AppId 的隔离安装、安装后启动、二进制一致性及卸载测试通过。没有替换现有正式安装。
  详细验证结果见交付目录的 VERIFICATION.json。

## 使用

关闭旧程序，安装 `MOOCDownloader-Setup-2.0.3-local.3-x64.exe`。
确认界面版本为 2.0.3-local.3，重新解析课程并添加下载。
旧版标为“不可下载”的记录需要移除记录后重新添加；移除记录会保留已下载文件。
请先选择一个视频验证，再按需添加其余视频。
