# 2.0.3-local.1 本地修复测试版

基于上游 v2.0.2 / 62221df，2026-11-09 制作，供本地安装测试，非上游官方 Release。

## 修复

- 登录身份验证支持网页实际返回的 JavaScript 对象字面量（无引号字段名、单/双引号字符串、嵌套数据和尾逗号），复用已有的纯 Python 数据解析器，不执行页面 JavaScript。
- 课程解析复用相同逻辑，保留已登录用户 ID，供后续资源签名使用。
- 昵称中的分号、花括号和引号不再破坏用户对象提取；后面的其他页面对象不混入身份数据。
- 视频加密与收费/未授权分开提示；接口同时提供未加密地址时选择未加密地址。
- 保留对未授权资源和不支持的加密 HLS 的拒绝处理。没有新增加密视频解密能力。

## 打包

Windows x64，Python 3.11.9，PyInstaller 6.22.2，Inno Setup 6.7.4；运行依赖见 requirements.txt。
FFmpeg 使用 Gyan 9.0.2 essentials（GPL-3.0-or-later），来源及许可证见 THIRD_PARTY_NOTICES.txt。

安装包名：MOOCDownloader-Setup-2.0.3-local.1-x64.exe。
应用内版本号：2.0.3-local.1。沿用原应用安装标识与用户数据目录，可覆盖升级。

## 本地验证结果

- `tests/login_regression.py`：9 项通过。旧版运行同一批测试可复现登录误判、用户 ID 丢失及视频类型误分类。
- `tests/test_v2.py`：33 项通过；`tests/task_removal_v2.py`：6 项通过。
- `tests/ui_v2.py` 通过；`tests/layout_v2.py` 的 9 种窗口/缩放组合通过。
- `tests/packaged_v2.py`：实际 exe 启动、FFmpeg 存在、WebView2 和无控制台登录结果加密传递通过。
- `tests/verify_installer.ps1`：临时安装、安装后启动、二进制哈希比对、许可证文件、卸载及测试用户数据保留全部通过。测试目录为 `_test_tmp/installed-v2`，没有安装到用户的正式应用目录。
- 真实匿名接口复查：目标课程首个视频明确报告加密视频暂不支持；《普通天文学》首个视频仍可解析为高清 MP4。未下载课程视频。

## 安装测试建议

1. 关闭旧程序，运行新安装包。
2. 在“设置”重新登录，确认出现“已验证登录”。内置浏览器里的登录不会自动传递给安装程序。
3. 重新解析课程，再添加或重试视频任务。
4. 若仍提示“源站返回加密视频”，说明该视频超出当前下载支持范围；记录新版报错即可，无需反复登录。

SHUFE-1486311164 的匿名抽样结果不能代表登录后源站一定返回同样的视频格式。真实账户的完整登录和该课程下载仍需用户安装后验证。
